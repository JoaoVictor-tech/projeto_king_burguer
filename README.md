# 🍔 King Burguer

Landing page moderna e responsiva inspirada em grandes redes de fast-food, desenvolvida com HTML, CSS e JavaScript puro.

O projeto apresenta uma experiência visual dinâmica com banners promocionais, menu interativo, área infantil, destaques de produtos e chamadas para download do aplicativo.

---

# 📸 Visão Geral

A aplicação foi criada com foco em:

* Design moderno e responsivo
* Experiência mobile-first
* Organização modular de estilos
* Componentização simples utilizando arquivos separados de CSS e JavaScript
* Navegação fluida entre seções
* Interface inspirada em aplicativos e sites de hamburguerias modernas

---

# 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Google Fonts
* Material Symbols
